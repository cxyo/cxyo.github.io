四个值得单独说的设计

这套系统的价值不在模型，在流程约束。

1 · 禁区红线（硬否决）

比提示词更重要的是不许说什么。内置各平台内容禁区、合规红线、极限词黑名单，在质检环节直接拦截 —— 不是给模型看建议，是不允许通过。

按平台与分级：红线 62 · 灰区 23 · 注意 14

2 · 素材台账（可追溯）

每条素材都带结论字段，且能查到它变成了系统的哪个能力。素材库不是收藏夹，是可检索的方法论数据库。

"值得借鉴": "标题用「数字+门槛」双元素，转/赞 21.72",
"用在哪": "标题生成公式 D",
"学习状态": "已用"

3 · 三维度效果判据

用三个独立维度判断内容，而不是笼统的"好"。关键是区分了转发倾向 ≠ 分发量级 —— 库里有一条视频转发/点赞 45，但点赞只有 1，它是小圈子自发转发，不是爆款。

传播力 = 转发 / 点赞
留存力 = 收藏 / 点赞
分发量级 = 绝对收藏数

4 · 按词锚定（改字即改片）

传统视频生成按秒切片，换文案就要重调时间轴。这里按词锚定：改一个字，时长自动重算；一套工作流沉淀下来，换内容出多个变体，结构不变。

anchor_by_words("短句")              # 1.60s
anchor_by_words("这是一句稍微长一点的话")  # 7.83s

快速开始

三步，从零跑出第一篇文章。

① 装依赖

git clone https://github.com/cxyo/opc.git
cd opc
pip install -r requirements.txt

② 填 Key

编辑 config/config.json，填入你的 DeepSeek API Key。

不想花钱？把 simulate 改成 true，全流程照跑。

③ 跑起来

cd 08_可运行系统
python run.py doctor
python run.py article --topic "你的选题"
